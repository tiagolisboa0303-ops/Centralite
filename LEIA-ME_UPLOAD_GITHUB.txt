CENTRAL LITE v1.7.4 - ROOT SEM POPUP REPETIDO

Correção principal:
- A Central Lite abre uma única sessão root persistente por execução do app.
- Os comandos de carga, tela e magiskpolicy reutilizam a mesma sessão.
- Isso evita abrir vários processos "su" a cada conexão/desconexão do SYNC.
- O Magisk deve pedir autorização apenas na primeira vez após abrir/reiniciar o app
  (e, se configurado como acesso permanente, não deverá repetir).

Upload:
1) Extraia este ZIP.
2) Envie o conteúdo para a RAIZ do repositório Centralite.
3) Substitua os arquivos existentes.
4) Faça commit na branch main.
5) Aguarde o workflow "Build Central Lite APK".

No tablet, na primeira solicitação do Magisk para a Central Lite:
- toque em CONCEDER / GRANT;
- se houver opção de duração, selecione PARA SEMPRE / FOREVER.
