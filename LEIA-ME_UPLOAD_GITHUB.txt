CENTRAL LITE v1.10.0 - SPOTIFY LEGACY + PAINEL WAZE

BASE
Base estável da v1.7.5. Carregamento/bateria, Ford SYNC, Wi-Fi, modo ECO e
demais automações foram preservados.

WAZE
- O mini-mapa da tela inicial foi removido visualmente.
- No mesmo espaço há agora um painel grande do Waze.
- Toque no painel Waze -> abre o Waze diretamente.
- Antes de abrir, a Central mantém a preparação de GPS/Alta Precisão já usada na v1.7.5.
- O botão Destino na faixa inferior continua disponível para pesquisar/enviar um destino ao Waze.

SPOTIFY
- O botão Música virou SPOTIFY.
- Toque curto: abre com.spotify.music.
- Se o Spotify não estiver instalado, a Central abre o diálogo da versão de teste:
  Spotify 8.4.94.817 / ARMv7 / Android 4.1+.
- Toque longo no Spotify: NewPipe continua disponível como fallback.
- Comando de voz "Spotify" ou "abrir música": tenta abrir Spotify.
- "YouTube" ou "NewPipe": continua abrindo NewPipe.

ARQUIVO EXTRA
Veja extras/SPOTIFY_ANDROID_5_TESTE.txt para a variante correta.

AVISO
O Spotify 8.4.94.817 é compatível tecnicamente com Android 5.1, mas é antigo.
O servidor atual do Spotify pode recusar login ou reprodução. Este pacote é justamente
para testar essa possibilidade no SM-T280.

UPLOAD
1. Extraia este ZIP.
2. Envie o conteúdo para a RAIZ do repositório Centralite.
3. Substitua os arquivos existentes.
4. Commit na branch main.
5. Aguarde o GitHub Actions.
